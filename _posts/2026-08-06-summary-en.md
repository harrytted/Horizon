## [Deno Releases Celld: Self-Hosted Distributed Durable Objects](https://github.com/denoland/celld) ⭐️ 8.0/10

Deno has unveiled Celld, a self-hosted runtime for distributed durable objects that replicates data to S3-compatible storage. The project is available on GitHub, offering a provider-independent implementation of the durable objects model. This matters because the durable objects abstraction, popularized by Cloudflare Workers, has been largely confined to a single cloud provider. Celld gives developers a self-hosted option, reducing vendor lock-in and enabling stateful serverless applications on their own infrastructure. In Celld's model, each durable object is addressed by name and is backed by its own SQLite database, which is replicated to an S3-compatible bucket that the user owns. The design follows the same single-threaded object model introduced by Cloudflare, but runs in a self-hosted environment.

hackernews · calvinfo · Aug 5, 16:50 · [Discussion](https://news.ycombinator.com/item?id=49185430)

**Background**: Durable objects are a cloud computing concept where each object is a single-threaded unit of computation that has its own persistent storage, addressed by name. Cloudflare Workers is the best-known implementation, and Cloudflare also open-sourced its runtime as workerd. Celld aims to offer the same abstraction outside of a specific cloud, using S3-compatible storage for replication.

## [The Valley of Webhooks: Streaming HTTP Subscriptions as a More Reliable Alternative](https://weli.dev/blog/the-valley-of-webhooks/) ⭐️ 8.0/10

The article analyzes practical problems with using webhooks for state synchronization and proposes a streaming HTTP-based subscription protocol as a more reliable alternative, which one commenter notes closely resembles the IETF's Braid-HTTP Subscriptions draft. Webhooks are widely adopted for real-time event delivery, but their reliability issues in state synchronization affect many API consumers. A standardized streaming HTTP subscription approach could improve data consistency and reduce integration complexity across the industry. The proposed solution uses a GET request with a 'Prefer: stream' header to maintain a persistent connection, addressing issues like signatures, deduplication, buffering, bootstrap, and cron-based polling. However, one commenter points out that persistent connections may be inefficient for low-frequency events and could hit CDN connection limits.

hackernews · weli · Aug 5, 15:22 · [Discussion](https://news.ycombinator.com/item?id=49184216)

**Background**: Webhooks are user-defined HTTP callbacks that allow real-time notifications when events occur, but they suffer from issues such as delivery failures, ordering, and idempotency. State synchronization is a challenge in distributed systems where multiple nodes must maintain a consistent view of shared data; HTTP streaming enables incremental delivery of response data over a persistent connection, which is different from media streaming like HLS or DASH.

## [Monodratic: Learned Product-Hash Routing for Sparse Causal Attention](https://www.reddit.com/r/MachineLearning/comments/1vg3jda/monodratic_learned_producthash_routing_for_sparse/) ⭐️ 7.0/10

Monodratic, a sparse causal-attention architecture using learned product-hash routing, achieves 99.35% mean accuracy on associative recall with only two selected remote blocks, far surpassing untrained routing (425/768) and local-only attention (151/768). The implementation is released as portable PyTorch with a proof paper and reproduction code. This shows that learned sparse routing can dramatically cut attention cost while staying highly accurate on memory-intensive tasks, potentially enabling longer-context models with fixed attention budgets. It also challenges the common assumption that sparse attention requires hand-crafted patterns, offering a data-driven alternative for efficient Transformers. The router selects two remote blocks from five eligible ones, reranks candidates via product probes, and always adds guaranteed local blocks before exact causal softmax. Experiments show agreement with an independent dense oracle to 1.43e-6 maximum error, and a fitted CPU timing exponent of 0.993 from 4,096 to 32,768 tokens. Limitations: synthetic experiments only, no fused kernel, and no claim of natural-language quality or deployment speed.

reddit · r/MachineLearning · /u/dttdrv · Aug 5, 10:28

**Background**: Causal attention, used in autoregressive Transformers like GPT, only lets each token attend to previous tokens, making sequence length scale quadratically in cost. Sparse attention methods approximate full attention by limiting each query to a few relevant keys, often using fixed patterns or hashing. RoPE (rotary position embedding) encodes token positions by rotating embeddings, which Monodratic uses to help route queries to relevant source blocks. Associative recall, a key capability for LLMs, tests whether a model can retrieve a value associated with a cue, such as finding a token linked to another.

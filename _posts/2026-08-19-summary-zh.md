## [Mojo 编程语言以 Apache 2.0 协议正式开源](https://simonwillison.net/2026/Aug/18/mojo-is-now-open-source/) ⭐️ 9.0/10

2026 年 8 月 18 日，Modular 以 Apache 2.0 许可证开源了 Mojo 编程语言，发布了其编译器和工具链。这是继上周 Mojo 1.0 发布之后的又一重要举措，兑现了自 2023 年 5 月以来的一项承诺。 Mojo 处于 Python 简洁性与高性能 AI/ML 计算的交汇点，开源能够推动更广泛的社区采用、贡献和信任。这可能加速 GPU 编程工具的发展，并使 Mojo 生态系统不再局限于单一厂商。 Mojo 最初计划成为 Python 的超集，但这一目标在 2025 年 8 月前后发生改变；如今它是一种独立语言，以受 Python 启发的语法专为 GPU 编程优化。该编译器基于 MLIR 框架构建，能够针对 CPU、GPU、TPU 及其他加速器生成代码。

rss · Simon Willison · 8月18日 21:39

**背景**: Mojo 是 Modular 公司开发的一种系统编程语言，将静态类型和借用检查器等受 Rust 启发的语义与类 Python 的语法相结合。它在 2023 年发布时曾以成为 Python 超集为目标，以带动自身生态发展，但该计划后来被放弃或推迟，Mojo 1.0 于 2026 年 8 月正式发布。由于 Mojo 基于多级中间表示（MLIR）框架构建，它可以为各种硬件生成高度优化的代码，因此非常适合需要比 Python 更高性能的 AI 工作负载。
